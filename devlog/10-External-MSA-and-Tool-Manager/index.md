Devlog 10 — External MSA and Tool Manager

This devlog covers external multiple sequence alignment integration.

Current direction:

treat MAFFT and Clustal Omega as external user-installed tools
configure executable paths
run alignment through subprocess and FASTA file I/O
open aligned results in a new viewer or replace the current viewer
show logs and alignment result actions

Future direction:

tool manager UI
official download guidance
path auto-detection improvements
clearer license notices
support for additional external tools after review
