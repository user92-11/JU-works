# Roadmap

## Phase 1 — Core Sequence Viewer

- FASTA import
- editable sequence viewer
- view/edit mode separation
- sequence selection and highlighting
- project save/load
- basic export

## Phase 2 — Mutation Inspection

- site-based mutation counting
- mutation tables
- logo plot
- heatmap
- binary/categorical mutation maps
- CSV and image export

## Phase 3 — Region-based Visualization

- region input parser
- entropy track
- valid sample size / coverage-like metrics
- gap and unknown-rate inspection
- panel, concatenate, and summary views
- region-level table export

## Phase 4 — Classification and Grouping

- label-based grouping
- typing rule presets
- similarity-based clustering
- simple tree-assisted grouping
- grouped FASTA export

## Phase 5 — Sanger Workflow Support

- AB1 file import
- chromatogram trace viewer
- raw / reverse-complement trace view
- sequence extraction into the main viewer
- manual trimming and editing workflow
- future consensus support for forward/reverse reads

## Long-term Ideas

- annotation layer
- region/gene map visualization
- improved large-alignment performance
- better project/session management
- documentation and tutorial datasets
