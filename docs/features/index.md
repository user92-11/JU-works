# Planned Features

## Sequence viewing and editing

- FASTA import
- editable sequence viewer
- view/edit mode separation
- copy, paste, delete, and trimming support
- project save/load

## Sanger workflow

- AB1 file import
- chromatogram trace viewer
- raw and reverse-complement trace view
- sequence extraction into the main viewer
- manual trimming and editing
- future forward/reverse consensus support

## Alignment and grouping

- multiple sequence alignment support
- label-based grouping
- typing rule-based classification
- similarity-based clustering
- simple tree-assisted grouping
- grouped FASTA export

## Mutation inspection

- site-based mutation inspection
- mutation count tables
- logo plot
- heatmap
- binary and categorical mutation maps

## Region-based visualization

- region parser
- entropy track
- valid sample size inspection
- gap and unknown-rate inspection
- panel, concatenate, and summary views
- CSV and figure export

## Annotation and maps

- persistent annotation layer
- region labels and notes
- future gene or region map visualization
